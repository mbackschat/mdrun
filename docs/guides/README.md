# Task guides

These guides are available offline through the installed executable. Choose a topic when your task needs its detail; ordinary command syntax and examples are in `mdrun COMMAND --help`.

| Command | Use it for |
| --- | --- |
| `mdrun guide documents` | Create, inspect, correct and verify executable Markdown |
| `mdrun guide sessions` | Prepare a cooperative binding, reuse an application and interpret routing/cleanup |
| `mdrun guide reference` | Exit statuses, input/output, paths, files, environment and remote delivery |

The maintained Markdown sources are [documents](documents.md), [sessions](sessions.md) and [reference](reference.md).
